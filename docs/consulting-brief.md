# 第0部：確定した理念・ビジョン・戦略・計画（本人執筆・正文）

以降の議論はすべてこのテキストを正とする。コンサルにもこれをそのまま渡してよい水準。

### 理念
就活は、多くの人にとって人生で初めて、学歴や経歴で篩にかけられ、選別される場所である。SHIN Careerは、その選別基準を「本人が磨いた自身の言葉」に置き換えるために、その場所を努力と磨かれた個性で測られる場所に変え、**情報と練習のインフラ**を提供する。

### ビジョン
就活における情報や練習機会の格差をなくし、一人でも多くの人が自分の言葉から個性を見つけ、それを表現し切ったと納得して就活を終えられる就活構造にする。テンプレ解答の暗記ではなく、自分の言葉を磨くことで価値を見出す社会へ。練習の機会は大学・地域・お金に左右されず、海外大生でも地方大生でも同じ回数練習できる状態にする。

### 戦略（二軸）
1. **情報の格差** — どの企業がどの段階で何を聞くかは、資金と人脈のある学生だけが持っている。企業リサーチと面接傾向DBは便利機能ではなく、格差を埋める**本体機能**。
2. **練習機会の格差** — AI面接練習自体は競合が無料で提供済み。空白は「**根拠を本人の発話の原文から示すフィードバック**」と「**模範解答への矯正ではなく本人の回答を最大化する方向の指摘**」。自己分析も品質基準は「出力が本人の言葉になっているか」の一点。

**練習の場と、企業に見せる場を構造的に分離する。練習データは企業に出さない。**
理由(1) 練習結果が採用に影響すると学生が知った時点で、練習は練習として機能しなくなる。
理由(2) 学生情報の企業提供は特定募集情報等提供事業の届出制・有料職業紹介の許可制の対象であり、2019年リクナビ事件で行政指導の前例がある。同意設計が曖昧なデータは企業側にも売れない。
企業に届くのは **①基準を超えた学生に付与されるバッジ**（面接内容は非開示）と **②本人が企業に見せる目的で意図的に作った自己分析** のみ。開示先の企業は学生が選ぶ。**法務確認が済むまで着手しない。**

### 計画
| 時期 | やること | 指標 |
|---|---|---|
| 2026年秋（〜12月） | **海外大生向けToCで二軸の質を検証** | 原文引用FBを受けた学生の回答の変化／企業研究DB・面接傾向データの件数と質 |
| 2027年春 | 国内就活シーズンへ展開 | 継続率／「納得して就活を終えられたか」の事後アンケート |

**二層マッチング**：スコアは裏側で候補を絞るためだけに使い、企業に最初に見せるのは**個性の側の文章**。企業は「フィット型（自社で活きている個性と入口が共通する学生）」と「補完型（今の自社に足りない素質を持つ学生）」を選べる。共通点は入口であってその先には異なる個性がある、という前提でフィット採用の同質化を避ける。

### 収益
学生課金だけでは成立しない前提。**中期＝大学・就活塾へのB2B2C／長期＝同意設計を伴う企業側課金（成功報酬型）**。数年で完成させる事業ではなく、**十年単位**で積み上げる。

# 第1部：この戦略の評価

## 1-1. 総評【提案】

**戦略文書としては、学生起業の相談として持ち込まれるものの中で明確に上位です。**特に次の3点は、多くの起業家が数年かけて痛い目を見てから学ぶことを、着手前に言語化できています。

- 「AI面接練習そのものでは差別化できない」と自分で認めている
- 「学生課金だけでは成立しない」と自分で認めている
- 「練習の場と見せる場を構造的に分離する」という**構造的な意思決定**をしている

**したがってコンサルには「事業計画を見てください」ではなく「この構造的な賭けが正しいか検証してください」と持ち込むべきです。**前者は添削を頼む態度、後者は判断を仰ぐ態度で、引き出せるものが違います。

## 1-2. 強い点（そのまま押し出すべき5つ）【提案】

**① 「練習データを企業に出さない」という自己規律**
これは収益機会を自ら捨てる決定です。ほとんどの就活サービスが逆をやり、だからこそ学生の信頼を失ってきた。**「捨てた」ことを明示的に語れば、それ自体が信頼の資産になります。**リクナビ事件を自分から引用できているのも良い。

**② 「本人の言葉を最大化する／模範解答に矯正しない」という品質基準**
これは理念と実装が一直線に繋がっている稀な例です。実際に添削エンジンが**回答から該当箇所を原文引用して**指摘を返す実装になっている【事実】ので、「言っているだけ」ではない。**デモで見せられる**のが強い。

**③ 海外大生というビーチヘッドの選び方**
教科書的に正しい選択です。理由を明示してください：
- 本人が当事者（＝Founder-Market Fit の実証）
- 母集団が小さく到達可能（＝小資本で全数に届く）
- **情報格差が構造的に最大**（日本にいないのでOB訪問も説明会も物理的に不可能）
- ボスキャリという**年1回の物理的な集合点**があり、獲得チャネルが具体的
- 相対的に支払い能力がある

**④ 「ボスキャリに出たいが出展費用が高くて出られない企業」というToBの入口**
これが今回の戦略で**いちばん筋がいい部分**かもしれません。既存の勝者（大手・ボスキャリ出展企業）と戦わず、**市場から締め出されている側**を顧客にする。予算の出どころも明確（採用費のうちボスキャリに払えなかった分）。「なぜ今SHINなのか」に対して、企業側から答えが出せる。

**⑤ 「十年単位」と「2028年まで企業側に着手しない」という時間軸**
短期のマネタイズ圧に負けない設計であることが伝わります。ただしこれは資金計画とセットでないと「甘い」と読まれる（→1-3⑤）。

## 1-3. 突かれる点（想定質問と、いま用意すべき答え）【提案】

**① 「海外大生は、そもそも恵まれている層では？ 理念の『格差をなくす』と矛盾しませんか」**
最も鋭い批判です。経済的階層で見れば海外大生は上位層。
→ 答え方：**あなたの理念は「経済格差」ではなく「情報・練習機会の格差」と定義されている**（文中でそう書けている）。海外大生は経済的には恵まれていても、**日本の就活情報網からは物理的に切断されている**。この二つは別の軸である、と切り分ける。そのうえで「海外大生はビーチヘッドであって理念の主戦場ではない。主戦場は2027年春以降の**地方大生**である」と明言する。ここを曖昧にすると理念が飾りに見えます。

**② 「就活塾へのB2B2Cは、理念と利益相反しませんか」**
就活塾はまさに「金を払える学生だけが機会を得る」構造の象徴です。そこに売るのは、格差をなくすと言いながら格差の再生産装置に武器を供給する形になりかねない。
→ 【要記入】ここは本人の答えが必要。取りうる整理は3つ：(a) 就活塾を外し**大学キャリアセンター・自治体・高専・地方大**に絞る、(b) 就活塾には売るが「SHIN単体は誰でも無料で使える」ことを担保として置く、(c) 塾を「配布チャネル」と割り切り理念とは別レイヤーとして説明する。**個人的には(a)が理念と最も整合し、かつ大学は予算があるので推奨。**

**③ 「バッジを、企業はなぜ信じるのですか」**
「基準を超えた学生」の基準の妥当性を誰が担保するのか。SHINが自称するだけのバッジには市場価値がありません。
→ 用意すべき答え：(i) 基準の中身を公開する（何をもって「個性を言葉で説明できる段階」とするか）、(ii) **予測妥当性のデータを蓄積する**（バッジ保持者の内定率・入社後評価）、(iii) 初期は「保証」ではなく「**この学生は話す価値がある、という推薦**」として売る。**(iii)から始めるのが現実的**【提案】。

**④ 「補完型マッチングを、企業は本当に買いますか」**
理念的には美しいが、採用の現場は保守的で、「今いない型の人材」を採る決裁は通りにくい。
→ 答え方：**フィット型を売り物にし、補完型はオプションとして併置する**。あるいは「補完型」を売るのではなく、企業側の自己分析の結果として「御社に足りない素質」を可視化し、**企業に気づかせてから**提示する。順序の問題です。

**⑤ 「Phase1で黒字化しなかったら、どうするのですか」**
【2026-09-08更新：一次回答あり】本人の設計は**二段階のリスク管理**になっている——Phase1（今シーズン・ボスキャリ）ではToC課金の黒字化を狙いつつ、**保険として自身の就活も並行して行う**。Phase1で結果が出れば、就活をやめてPhase2（日本市場・法人としての本格展開）に全振りする。**これ自体は堅実な設計**で、単に「学生の壮大な構想」ではなく「検証してから賭ける」構造になっている。

ただし、コンサルには次の2点を詰められます。用意すべき答えを示す：

- **「黒字化」の基準は何か。** 数百人規模の海外大生からの課金でAI原価をわずかに上回れば「黒字」と言えてしまうが、それは**Phase2に全振りする根拠としては弱すぎる**。「黒字化」ではなく「**月商◯◯円、有料ユーザー◯◯人、継続率◯◯%になったらPhase2に進む**」という具体的な閾値を、Phase1が終わる前に自分で決めておくべき。→ 第4部で質問。
- **今この瞬間、就活とSHINの両方に時間を割いている。** ちょうどPhase1の検証期間（ボスキャリまでの2ヶ月、第3部参照）が就活の繁忙期と重なる。**保険をかけることと、検証に本気を出すことはトレードオフになりうる。** どちらにどれだけ時間を配分するかは、コンサルに相談する価値がある論点。

→ ここが具体的な数字で詰められれば、他がどれだけ良くても「学生の壮大な構想」で終わっていた懸念は大きく解消される。

**⑥ 「ChatGPTで練習すればよくないですか」**
→ 用意済みの答え：(i) 学生はプロンプトを設計できない、(ii) **109社の実出題DB**は汎用LLMが持っていない、(iii) ルールベースなので評価が揺れない、(iv) Webテストの形式再現・無限生成は汎用LLMにできない、(v) 復習ノート・壁打ち・スコア推移という**継続の器**がある。
→ 正直に添えるべき点：**この差は永続しない**。だからこそデータの蓄積と企業DBに投資する、という論の運びが誠実で強い。

**⑦ 「企業リサーチDB・面接傾向データの出所は？」**
現在の実出題データは就活体験談サイト（ワンキャリア・就活会議・unistyle・外資就活ドットコム等）を「もとに編集」したもの【事実・アプリ内明記済み】。
→ 無料デモなら黙認されても、**課金・ToB化した瞬間に権利面が顕在化**します。戦略文書で「事実ベースの企業研究DBの件数と質」を2026年秋の指標に置いている以上、**自前収集への移行計画**が要る。→ 第4部で質問。

**⑧ 「海外大生市場は小さすぎませんか」**
【要検証】ボスキャリ参加学生の規模を一次情報で押さえること。
→ 答え方：ビーチヘッドの目的は売上ではなく**二軸の質の検証**である、と目的を先に置く。そのうえで「ここで質が証明できたら国内に横展開する」橋を具体的に示す。

# 第2部：★最重要 — 「言っていること」と「動いているもの」のギャップ

**このセクションが今回いちばん重要です。**

あなたは「1番の強みは、その人の弱点を分析してその人だけの問題集や提案をしてくれる仕組み」と書きました。**戦略としては完全に正しい**（機能の多さではなくパーソナライズの質、という位置づけは、二軸戦略とも整合します）。

| バッジ／マッチング | ❌ 未実装（2028年以降の構想） | 想定通り |

### これが何を意味するか【提案】

コンサルに「1番の強みはパーソナライズです」と言い、その場でデモを触ってもらうと、**「それはどこにあるんですか」となります。**一度これが起きると、他の主張の信頼度もまとめて下がります。

**対処は簡単で、順序を変えるだけです。**

> 「**動いているのはここまで**です（面接練習・原文引用FB・Webテスト無限生成）。**次に作るのがここ**です（弱点の蓄積 → 個別ドリル・自己分析・企業リサーチ）。今日は**その順番が正しいか**を相談したい」

これなら、ギャップは弱みではなく**アジェンダそのもの**になります。1-1で述べた「判断を仰ぐ態度」と一致します。

### 優先順位についての私見【提案】

限られた時間で1つだけ作るなら、**Webテストの「誤答・時間超過の記録 → 苦手分野の特定 → 出題比率の調整」を推します。**理由：

- 実装コストが最も低い（既存の生成エンジンに記録層と出題重み付けを足すだけ。自己分析や企業リサーチのようなゼロからの新規開発ではない）
- あなたの主張（「チート文化の原因は問題集が少ないこと。無限提供＋苦手特化で解決する」）を**証明する最短経路**
- 「無限に出る」だけなら競合も言えるが、「**解くほど自分専用の問題集になる**」は言えない。ここが差別化の実体になる
- 数値で効果を示せる（苦手分野の正答率の推移）＝検証指標として使える

自己分析は理念的には中核ですが、**品質基準（「出力が本人の言葉になっているか」）を満たす実装が最も難しく、AI原価もかかる**。2026年秋の検証には間に合わせにくい。
